# Dardachat — site vitrine

Site Next.js statique, prêt à être déployé sur Vercel.

## Lancer en local

```bash
npm install
npm run dev
```

## Déployer sur Vercel

Importez ce dossier dans Vercel, puis conservez les réglages automatiques : la commande de build est `npm run build` et le dossier de sortie est `out`.

## Avant publication

Le numéro de téléphone, les horaires et les tarifs n’étaient pas lisibles depuis les fichiers HEIC fournis dans cet environnement. Recherchez `XXXXXXXXX`, `à renseigner` et `—` dans `app/page.tsx` pour les remplacer par les informations confirmées. Les photos HEIC peuvent être converties en JPG/WebP puis ajoutées dans `public/` pour remplacer les visuels de la galerie.
